TRANSLATION CARD (Vedanta Yojana). Follow it exactly; it replaces docs/TRANSLATION-GUIDE.md for this task.

TASK
Translate each English item in ITEMS into the language listed in the batch header (normally one language per batch: work proceeds one language at a time, in the order hi, ta, kn, te). The items are prose only: verses, name lines and mantras are already generated by script and are not in the list.

OUTPUT
Reply with one JSON object and nothing else, no code fences, no comments:
{"ta": [...], "kn": [...], "te": [...], "hi": [...]}
Include only the languages in the header. Each array has exactly as many strings as ITEMS, in the same order: element i translates item i. Never merge, split, skip or reorder items. Never put a blank line (two newlines) inside a string.

FIDELITY
- English is the source of truth: add nothing, drop nothing, summarise nothing, improve nothing. No invented explanations.
- Register: dignified, traditional, scholarly and devotional, in the literary register of the Vadakalai Sri Vaishnava sampradāya and faithful to Viśiṣṭādvaita Siddhānta. Natural, grammatical and accessible to educated general readers. No unnecessary ornamentation, artificial archaism, over-Sanskritisation, colloquialism or embellishment. Register never overrides fidelity: the English still governs every word. The Divya Desam pages remain the model.
- If an item is garbled or a placeholder, translate nothing for it and output the single word DEFECT in that slot for every language.
- If an item is translatable but ambiguous or apparently wrong in the English (it says something the author probably did not mean), translate it faithfully and record it in an optional "concerns" key inside the same JSON object: "concerns": [{"item": 5, "note": "reads as if the stotram were one of the commentaries; probably his commentary on it"}]. The owner settles the English; never correct it yourself.

REGISTER
- Reverent and formal, never colloquial. No calques from English or Hindi, no newspaper phrasing.
- Use the tradition's own words where they exist: a sage's teaching is உபதேசம் / ಉಪದೇಶ / ఉపదేశం / उपदेश, not "advice"; what a sage or the Lord imparts is அருளிச்செய்யப்பட்டது in Tamil, not கொடுக்கப்பட்டது; bondage is தளை in Tamil; Bhishma's bed of arrows is அம்புப் படுக்கை / ಶರಶಯ್ಯೆ / అంపశయ్య.
- Prefer the elevated word over the everyday one where both are plain enough to read (te ఉత్తమ పరిపాలనా దక్షులు over మంచి పాలకులు; శ్రేష్ఠ over మంచి).
- Epic kinship words keep their epic sense: "brothers" stays சகோதரர்கள் / ಸಹೋದರರು / సోదరులు / भाई even where cousins are meant.

DOCTRINE
- Add no doctrinal claim, devotional embellishment or emphasis the English does not have. In particular, never add a restrictive or emphatic particle ("only", "alone"; ஏ / ಏ / ही / ే) that the English lacks: it can change doctrine ("bhakti yoga only" silently excludes prapatti).
- Use the approved terms for prapatti / śaraṇāgati, bhakti yoga, moksha, paramapadam, kainkaryam, āchārya sambandham and the Lord's attributes, as the glossary gives them.
- If the English seems doctrinally questionable, translate it faithfully and record it under "concerns". Never correct it silently.

CONSISTENCY
- One person, one form, all chapter long: never switch the same sage, deity or king between plain and honorific mid-paragraph. Keep the glossary's choice (e.g. kn ಭೀಷ್ಮನು but ವ್ಯಾಸರು; ta பீஷ்மர் but யுதிஷ்டிரன்).
- Tamil keeps its doubling after demonstratives and case endings (இந்தக் கேள்வி, உலகிற்குக் கிட்டாமல்).

SCRIPT
- Clean Unicode in the target script only: no Devanagari letters inside Tamil, Kannada or Telugu words (avagraha is ಽ / ఽ, visarga ಃ / ః / ஃ), no word starting with a vowel sign or virama, no broken conjuncts. The merge step rejects any of these.

INSIDE PROSE
- Sanskrit or Tamil words quoted in IAST inside a sentence (e.g. "(sarvāṇi bhūtāni svatantraḥ sṛjati)") are written in the target script, never translated; keep their brackets and quotes. Hindi writes them in Devanagari.
- Gloss pattern "word (term)" becomes "translated word (term in target script)". Never repeat the translated word inside the brackets.
- A short item with no final punctuation is a sub-heading: translate it short, still with no final punctuation. A sentence that ends with a full stop keeps one.
- Keep list markers exactly (1. 2) (i) a) •) and a leading * on a note.
- Western digits 0-9 only. Straight double quotes "...". A space after every comma and semicolon; no space inside brackets; a space before "(" after a word; no space before , or .
- Titles: translate; keep numbers and dashes ("Naama 1-5: ..." -> நாமம் 1-5 / ನಾಮ 1-5 / नाम 1-5 / నామ 1-5).

LANGUAGES
- ta Tamil: Tamil-root forms a Tamil Sri Vaishnava reader uses (பெருமாள், ஆழ்வார், தாயார், சுதர்சனம்). Sri = ஸ்ரீ. Grantha letters only where the glossary uses them.
- kn Kannada: Sanskrit forms (ಭಗವಂತ, ಆಚಾರ್ಯ, ಮೋಕ್ಷ). Kannada script only, no Telugu letters. Sri = ಶ್ರೀ.
- te Telugu: Sanskrit roots (మోక్షం, ఆచార్యులు). Telugu script only, no Kannada letters. The Lord = స్వామి with SINGULAR verbs. Sri = శ్రీ.
- hi Hindi: Sanskrit-rooted, formal (भगवान, आचार्य, मोक्षम्); technical terms keep -म् (वाहनम्, उत्सवम्, स्तोत्रम्); long े/ो in names. Sri = श्री.

HONORIFICS
The Lord: ta பெருமாள்/எம்பெருமான், kn ಭಗವಂತ/ಭಗವಾನ್, hi भगवान, te స్వామి/పరమాత్మ (singular). Pronoun for Bhagavān: ta அவர் with honorific -ார் verbs (never அவன்); te ఆయన, with the singular verbs above (never అతడు for the Lord); hi honorific (वे / उन्होंने); kn the established singular forms of approved Kannada devotional prose (ಅವನು / ಭಗವಂತನು), with honorific forms allowed where the context calls for them; never apply Tamil or Telugu pronoun conventions to Kannada. Never a casual pronoun for Bhagavān, Mahālakṣmī, the Āzhwārs, Āchāryas or Ṛṣis.
Āzhwārs, Āchāryas (Sri Bhattar, Sri Rāmānuja, Sri Sankara), Thāyār, Garuḍa, Sudarshana take honorific plural verbs in every language; Āṇḍāl the feminine honorific.

TERMS
GLOSSARY lines in the batch are binding: write those terms exactly as given for each language.
A recurring name or technical term NOT in the glossary: choose the most standard Sri Vaishnava form, use it the same way in every item, and record it in an optional "terms" key inside the same JSON object, so later batches reuse it:
"terms": [{"en": "Nirukti", "ta": "நிருக்தி", "kn": "ನಿರುಕ್ತಿ", "te": "నిరుక్తి", "hi": "निरुक्ति"}]
Only proper names and technical terms, not ordinary words. Never write anything outside the JSON object.
