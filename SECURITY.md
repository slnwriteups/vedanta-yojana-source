# Security Policy

Vedanta Yojana takes the security of its users and its source repository seriously.

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, its build/release
pipeline, or the deployed application, please report it privately rather than
opening a public issue or pull request.

Use GitHub's private vulnerability reporting for this repository:

1. Go to the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Provide as much detail as possible: affected component, reproduction
   steps, and potential impact.

Please give the maintainer a reasonable opportunity to investigate and
address the issue before any public disclosure.

## Scope

This policy covers:

- The source code and configuration in this repository
- The GitHub Actions build and deployment pipeline
- The published GitHub Pages website and any GitHub-distributed release
  artifacts

## What to Expect

- Acknowledgement of your report as soon as practical.
- An assessment of the issue and, where confirmed, a remediation timeline.
- Credit in the fix's release notes, if you would like it and it is
  appropriate to the disclosure.

Please do not include real credentials, personal data, or other sensitive
material in a report. A description of the issue and steps to reproduce it
is sufficient.
