# /content

This directory is the future application's content layer — Git-tracked
Divya Desam, Library (book/chapter), and Knowledge records, per the
approved Phase 4B/5A architecture.

**Status: intentionally empty.** No content has been migrated. This
scaffold phase (5B) does not migrate anything.

Planned subdirectories (not yet created/populated):

- `divya-desams/` — one JSON record per Divya Desam (target: 108 records,
  all `status: "draft"` on first migration, per the corrected Phase 5A
  publication policy)
- `library/` — book metadata + chapter MDX files
- `knowledge/` — standalone Knowledge MDX records

Nothing under this directory is read by `content-extraction/` or by the
historical SAP export, and nothing under this directory is generated by
copying/transforming those sources yet. That transformation is Phase 5E–5H,
gated by a single-record (Sri Rangam) migration and human review checkpoint
before the full 108-record migration runs.
